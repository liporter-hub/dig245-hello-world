Tutorial and Summary

Networks

The very basis of networks relies on IP addresses, which is the indentifying adress for sending/receiving internet traffic. A Domain Name System (DNS) gives these IP addresses fun, easy to remember names(domains). It's much easier to remember "Google.com" than its long IP address

It is also important to know network commmands from the terminal:

  • whois contains records and domain ownership.(info held by several registries)
  • ping checks network connectivity and latency, kind of like poking the website to see if its awake
  • traceroute is used for troubleshooting by providing info about latency as well as individual node identification
  • curl has several different functions for requesting resources. fetching then saving a source to your computer, displaying it in shell, displaying headers, etc.

There are many other advanced network commands, as well as network testing/observation tools, like Nmap and Wireshark
